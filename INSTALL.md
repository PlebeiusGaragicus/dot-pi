# Install

See [docs/install.md](docs/install.md) for full documentation.

**Prerequisites:** Node.js / npm (required for pi itself and for extension dependencies).

**Quick start:**

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/PlebeiusGaragicus/dot-pi/main/install)"
```

The installer runs `npm install` in the dot-pi root to fetch runtime extension
dependencies (e.g. `typebox`). If you cloned manually, run `npm install` yourself.
