# retro

Retrospective trajectory analysis team. Analyzes workspace directories from other teams.

## Usage

Typically invoked via `run-retro`, but can also be used directly:

```
retro                              # interactive session in current directory
```

## See also

```
run-retro <team>                   # analyze latest workspace for a team
run-retro <team> --list            # list workspaces
run-retro <team> --pick            # choose interactively
run-retro <team> -- "focus hint"   # with steering prompt
```
