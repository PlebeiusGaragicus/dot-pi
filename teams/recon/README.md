# recon

Reconnaissance and planning team for codebase exploration. Runs in a workspace.

## Usage

```
recon "explore the auth system"    # new workspace session
recon --list                        # list past workspaces
recon --resume                      # resume latest workspace
```

## Retrospective

```
run-retro recon                    # analyze latest workspace
run-retro recon --pick             # choose a workspace interactively
```
