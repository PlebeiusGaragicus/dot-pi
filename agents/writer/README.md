# writer

Writing and documentation assistant — prose, editing, and repo docs. Runs in-situ like `coder`, without plan-mode (`/plan` is not available).

## Usage

```
writer                          # interactive session
writer - "polish this section" # prompt, then stay interactive
```

## Configuration

- `APPEND_SYSTEM.md` — append notes for tools and behavior (pi default prompt stays)
- `pi-args` — default CLI flags
